    The overlay draws on top of the game, so set League's Window Mode to Borderless or Windowed (Settings → Video). Exclusive fullscreen hides other windows.

    Performance

    Off by default, so the app draws on the CPU and doesn't compete with League for the GPU. On some graphics cards, turning it on lets Windows show the overlay with less FPS cost. Try both and keep whichever runs better.

    Restart the app to apply this change.
